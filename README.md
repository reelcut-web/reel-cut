## What it does

**Script → storyboard → search [1M+ B-roll](https://reelcut.video/en/stock) by each shot sentence → voiceover → [CapCut / 剪映 draft](https://reelcut.video/en/capcut-export) for second edit.**

| | |
|---|---|
| **Million-clip library** | Semantic search by full shot line; daily cap on plan, search/download not metered like per-click APIs. |
| **Search API** | `POST https://reelcut.video/api/v1/clips/search` — same library as the studio. [API page](https://reelcut.video/en/api) |
| **AI video** (separate) | Text / image / lip sync in Dashboard → Video Gen. **Low $/second vs typical hosted AI video (~$0.08–0.15/s)** — from about **$0.017/s** (480p fast, starter credit pack); **billed per second only when render succeeds.** [Pricing](https://reelcut.video/en/pricing) |
